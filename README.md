🗳️ SecureVote

SecureVote is a blockchain-based fingerprint voting system designed to provide a secure, transparent, and tamper-proof voting experience. The system uses fingerprint authentication to verify voter identity and blockchain technology to ensure vote integrity. It also supports offline vote collection with secure synchronization when an internet connection becomes available, making it suitable for rural and low-connectivity areas.

✨ Features

- 🔐 Fingerprint-based voter authentication
- ⛓️ Secure vote storage using blockchain
- 🌐 Offline voting with automatic synchronization
- 📊 Admin dashboard for election management
- 🧾 QR code generation for vote verification
- 🌍 Multi-language support
- 🛡️ One person, one vote

🛠️ Technologies Used

- React.js
- JavaScript
- Python
- Flask
- SQLite
- Blockchain
- HTML
- CSS

🚀 Installation

1. Clone the repository.
2. Install the required dependencies.
3. Start the backend server.
4. Run the frontend application.
5. Open the application in your browser.

🎯 Purpose

The goal of SecureVote is to create a reliable, transparent, and accessible digital voting platform that improves election security while supporting areas with limited internet connectivity.
